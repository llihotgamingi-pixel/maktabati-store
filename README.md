# مكتبتي | Maktabati - النسخة النهائية للتسليم

هذه هي النسخة النهائية والجاهزة تماماً للعمل (بدون أي مشاكل في قاعدة البيانات).

## أسهل طريقة للتشغيل:
فقط اضغط مرتين على ملف `start_project.bat` الموجود في هذا المجلد.
- سيقوم الملف تلقائياً بتثبيت كل شيء.
- سيقوم بتشغيل السيرفر والواجهة.
- سيفتح المتجر في متصفحك تلقائياً.

إذا كنت تستخدم Mac أو Linux، استخدم الأوامر:
1. `npm run install:all`
2. `npm run dev`
